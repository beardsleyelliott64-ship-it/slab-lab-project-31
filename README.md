# SlapLab VR — Quest 3 fixed build package

Unity 6000.0.66f2. Standalone Android Quest 3 prototype.

Features:
- Quest/Oculus XR provider configuration
- tracked left/right controller hands
- physical velocity-based slap detection
- face hit zone, hit power, combo and score
- 60 second round
- haptic feedback
- impact particles and synthesized impact audio
- procedural arena and HUD
- no external art assets required

Project root must contain Assets, Packages and ProjectSettings.
